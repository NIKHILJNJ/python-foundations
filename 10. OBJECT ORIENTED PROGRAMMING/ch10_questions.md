# Chapter 10 — Practice Set: Object Oriented Programming

1. Create a class "Programmer" for storing information about a few programmers working at Microsoft.
2. Write a class "Calculator" capable of finding the square, cube, and square root of a number.
3. Create a class with a class attribute `a`; create an object from it and set `a` directly using `object.a = 0`. Does this change the class attribute?
4. Add a static method to problem 2, to greet the user with "hello".
5. Write a class "Train" which has methods to book a ticket, get status (number of seats), and get fare information for a train running under Indian Railways.
6. Can you change the `self` parameter inside a class to something else (say "nikhil")? Try changing `self` to `slf` or `nikhil` and see the effects.
