# Chapter 09 – File I/O

A beginner-friendly guide to reading and writing files in Python.

## 📖 Overview

Random-access memory (RAM) is **volatile** — all its contents are lost once a program terminates. In order to persist data permanently, we use **files**.

A file is data stored on a storage device. A Python program can talk to a file by **reading** content from it and **writing** content to it.

## 🗂️ Types of Files

There are 2 types of files:

| Type | Description | Examples |
|------|-------------|----------|
| Text files | Store human-readable text | `.txt`, `.c` |
| Binary files | Store data in binary format | `.jpg`, `.dat` |

Python has a lot of functions for reading, updating, and deleting files.

## 📂 Opening a File

Python has an `open()` function for opening files. It takes 2 parameters: **filename** and **mode**.

```python
# open("filename", "mode of opening (read mode by default)")
open("this.txt", "r")
```

## 📖 Reading a File in Python

```python
# Open the file in read mode
f = open("this.txt", "r")

# Read its contents
text = f.read()

# Print its contents
print(text)

# Close the file
f.close()
```

### Other Methods to Read a File

You can also use `f.readline()` to read one full line at a time:

```python
f.readline()  # Read one line from the file
```

## 🔑 Modes of Opening a File

| Mode | Description |
|------|-------------|
| `r` | Open for reading |
| `w` | Open for writing |
| `a` | Open for appending |
| `+` | Open for updating |
| `rb` | Open for reading in binary mode |
| `rt` | Open for reading in text mode |

## ✍️ Writing Files in Python

In order to write to a file, first open it in write or append mode, then use Python's `f.write()` method to write to it:

```python
# Open the file in write mode
f = open("this.txt", "w")

# Write a string to the file
f.write("this is nice")

# Close the file
f.close()
```

## 🧰 The `with` Statement

The best way to open and close a file automatically (without needing to explicitly call `f.close()`) is the **`with`** statement.

```python
# Open the file in read mode using 'with'
with open("this.txt", "r") as f:
    # Read the contents of the file
    text = f.read()
    # Print the contents
    print(text)
```

The file is automatically closed once the `with` block ends — even if an error occurs inside it.

## ✅ Summary

- Files let you persist data beyond the lifetime of a program.
- Python distinguishes between text files and binary files.
- `open()` opens a file with a given mode (`r`, `w`, `a`, `+`, etc.).
- `f.read()` and `f.readline()` read file contents; `f.write()` writes to a file.
- Always close files with `f.close()` — or better, use the `with` statement to handle this automatically.
