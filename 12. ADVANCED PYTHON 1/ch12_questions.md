# Chapter 12 — Practice Set: Advanced Python 1

1. Write a program to open three files, `1.txt`, `2.txt`, and `3.txt`. If any of these files are not present, print a message without exiting the program.
2. Write a program to print the third, fifth, and seventh elements from a list using the `enumerate` function.
3. Write a list comprehension to print a list containing the multiplication table of a user-entered number.
4. Write a program to display `a/b`, where `a` and `b` are integers. If `b = 0`, display "infinite" by handling the `ZeroDivisionError`.
5. Store the multiplication tables generated in problem 3 in a file named `Tables.txt`.
