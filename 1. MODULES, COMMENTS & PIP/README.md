# Chapter 01 — Introduction, Modules, Comments & Pip

## What is Programming?

Just like we use Hindi or English to communicate with each other, we use 
programming languages like Python to communicate with computers.

Programming is the process of giving instructions to a computer so it can 
perform tasks, solve problems, and automate work.

## What is Python?

Python is one of the easiest and most beginner-friendly programming 
languages. Its syntax feels close to simple English, which makes it easy 
to read, write, and understand.

Python is widely used in web development, automation, artificial 
intelligence, machine learning, data science, and software development.

## Features of Python

1. Easy to learn, beginner-friendly syntax.
2. Free and open source.
3. Works on Windows, Linux, and Mac systems.
4. Widely used in modern technologies and AI.

## Installation

Python can be downloaded from [python.org](https://python.org). Download 
the installer for your operating system and complete the setup process.

---

## Your First Python Program

Create a file called `hello.py` and paste the following code into it:

```python
print("hello world")   # print is a function
```

Execute this file by typing `python hello.py` in the terminal — you'll 
see "hello world" printed on the screen.

## Modules

A **module** is a file containing code written by somebody else, which 
can be imported and used in our own programs.

## Pip

**Pip** is the package manager for Python. You can use pip to install 
external modules on your system.

```bash
pip install flask
```

## Types of Modules

There are two types of modules in Python:

1. **Built-in modules** — preinstalled with Python (e.g. `os`, `random`).
2. **External modules** — need to be installed using pip (e.g. 
   `tensorflow`, `flask`).

---

## Python as a Calculator (REPL Mode)

We can use Python directly from the terminal by typing `python`. This 
opens the **REPL** (Read Evaluate Print Loop) — a way to run Python code 
interactively, line by line, without saving it to a file first.

---

## Comments

Comments are used to write something which the programmer does not want 
to execute. They can be used to explain code, mark author names, dates, 
or add notes.

### Types of Comments

There are two types of comments in Python:

**Single-line comments** — start with a `#` symbol:

```python
# This is a Single-Line Comment
```

**Multiline comments** — written using triple quotes:

```python
"""
This is an amazing
example of a Multiline
comment!
"""
```
