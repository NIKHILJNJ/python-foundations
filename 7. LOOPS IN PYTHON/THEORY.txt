What is a Loop?
Sometimes we need to repeat a block of code multiple times (e.g., printing numbers from 1 to 1000). Loops allow programmers to automate repetitive tasks cleanly and efficiently.

Types of Loops
Python primarily supports two types of loops:

while loop

for loop

1. while Loop
A while loop continuously executes a block of code as long as a specified condition remains True.

Syntax
Python
while condition:
    # Body of the loop
⚠️ Important Note: In a while loop, the condition is evaluated first. If it never becomes False, the loop will run infinitely! Always ensure the loop variable gets updated.

Example
Python
i = 0
while i < 5:
    print("Harry") # Prints "Harry" 5 times
    i = i + 1
2. for Loop
A for loop is used to iterate over a sequence (such as a list, tuple, string, or range).

Syntax & Example
Python
l = [1, 7, 8]

for item in l:
    print(item)  # Prints 1, 7, and 8
The range() Function
The range() function generates a sequence of numbers. It is commonly used with for loops.

Python
range(start, stop, step_size)
Default start: 0

Default step_size: 1

stop: Non-inclusive (stops at stop - 1)

Example
Python
# Prints numbers from 0 to 6
for i in range(0, 7): # Equivalent to range(7)
    print(i)
Loop Control Statements
for with else
An optional else block executes only when the loop finishes normally (i.e., exhausts all items without hitting a break).

Python
l = [1, 7, 8]

for item in l:
    print(item)
else:
    print("Done")  # Executed after the loop finishes
The break Statement
break is used to exit the loop immediately, skipping all remaining iterations.

Python
for i in range(0, 80):
    print(i)
    if i == 3:
        break  # Loop exits here (prints 0, 1, 2, 3)
The continue Statement
continue skips the current iteration and jumps directly to the next one.

Python
for i in range(4):
    if i == 2:
        continue  # Skips printing when i is 2
    print(i)      # Prints 0, 1, 3
The pass Statement
pass is a null statement in Python. It serves as a placeholder where code is syntactically required but no action is needed.

Python
l = [1, 7, 8]

for item in l:
    pass  # Prevents syntax errors in an empty loop
